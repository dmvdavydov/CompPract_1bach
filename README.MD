## О РЕПОЗИТОРИИ

Репозиторий для хранения материалов и исходников кода для курса "Компьютерный практикум" учебный год 2026/27 направление "Математика и компьютерные науки" бакалавриат 1 курс.

## Содержание
- [Структура](#структура)
- [Задания](#задания)
- [Вопросы и обсуждения](#вопросы-и-обсуждения)

## Структура

|

|-> materials

|   Будет содержать материалы пар презентации, какие-то вспомогательные файлы, если потребуется.

|-> sources

|   Будет содержать исходники кодов, примеры и т.п

## Задания
Максимальное количество баллов за каждое задание будет определяться позже. Однако для заданий будет установлен дедлайн (срок будет указываться в тексте задания).

По истечению дедлайна работы МОЖНО будет досдать, но максимальное количество баллов за задание будет уменьшено.

Задания будут публиковаться в блоке `Issues` отдельными пунктами. Предлагается ответы и решениия на задания публиковать в комментариях к соответствующему `issue`.

## Вопросы и обсуждения
Во вкладке `Discussions` есть общий пост, в обсуждении которого можно задавать вопросы, обсуждать какие-либо вещи и т.п.

Также можно написать мне лично на университетскую почту, либо привязанный к ней аккаунт яндекс мессенджера. Либо в тг, но лучше не надо.
