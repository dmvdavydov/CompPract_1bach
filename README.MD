## Задания
Максимальное количество баллов за каждое задание будет определяться позже. Однако для заданий будет установлен дедлайн (срок будет указываться в тексте задания).

По истечению дедлайна работы МОЖНО будет досдать, но максимальное количество баллов за задание будет уменьшено.

Задания будут публиковаться в блоке `Issues` отдельными пунктами. Предлагается ответы и решениия на задания публиковать в комментариях к соответствующему `issue`.

## Сдача заданий
Каждому студенту предлагается создать ПРИВАТНЫЙ репозиторий на github с названием CompPract_homework.
Меня (https://github.com/dmvdavydov) нужно добавить в соавторы (внутри вашего репозитория в настройках (значёк шестерёнки) раздел Collaborators).

В репозитории создать папку homework.
Скрипты решения заданий из Issues публиковать в папке homework с названием файла task_dd_mm_yy.java,
где dd_mm_yy дата публикования мной заданий (будет в названии issue), например, для задания от 09.09.26 название скрипта будет выглядеть:
task_09_09_26.java

Внутри скрипта в первой строке нужно будет опубликовать строчный комментарий с ссылкой на issue с заданием. Далее решение задания например:
```Java
// https://github.com/dmvdavydov/CompPract_1bach/issues/3
public class task_09_09_26 {
    public static void main(String[] args) {
        /*
            Здесь ваш код
        */
    }
}
```

В комментариях к каждому домашнему заданию в issue нужно опубликовать ссылку на ваш конкретный скрипт в вашем репозитории.
